مرآة — حزمة مهيأة للنشر على Firebase Hosting

هذا الملف ليس موقعًا منشورًا؛ يحتوي على مجلد public الذي يُنشر ومعلومات تهيئة Firebase.
يجب نشر قواعد Firestore بصورة منفصلة قبل تمكين كتابة القصص والتعليقات.
لا تفتح قاعدة البيانات لجميع المستخدمين. قواعد Storage تتطلب إعداد Storage وقد تتطلب Blaze.
التحقق الهاتفي الفعلي على الويب يحتاج reCAPTCHA وإعدادات النطاق المصرح به وقد يخضع لحد الرسائل والفوترة.

لمن لديه بيئة Node.js وFirebase CLI:
1) فك الضغط وافتح مجلد الحزمة الذي يحوي firebase.json
2) firebase login
3) firebase deploy --only hosting --project miraa-app-bbb4d
4) بعد مراجعة قواعد الأمان، يمكن نشرها بأمر firebase deploy --only firestore:rules

لا تشغل هذه الأوامر داخل متصفح الآيفون. يجب استخدام بيئة نشر مناسبة.
ميزات توليد الفيديو والدفع والمكافآت غير متصلة بمزود إنتاجي.
